# Цель и критерии завершения

Ожидаемое поведение, ограничения, что проверяем перед завершением.
Для автоматически проверяемого поведения: первый сценарий, уровень теста и команда.
При исключении из TDD: альтернативная проверка и недоступное обязательное окружение, если есть.
При влиянии на производительность: сценарий/нагрузка, метрика и бюджет,
исходный замер и способ сравнения. Непроверенные числа обозначай как предложения.
