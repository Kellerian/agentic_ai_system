# Планирование

Прочитай `AGENTS.md`, применимые правила и `.codex/project.md`; определи цель и ограничения.
При запросе сохранить готовый согласованный план сделай это сам, без повторного исследования и агента.
Для небольшой ясной задачи составь краткий план сам. Для неизвестных зависимостей
или сложной декомпозиции делегируй `kit_planner` по
[runtime](../dev-cycle/references/runtime.md), передав только контекст задачи.

Формат результата — по запросу; read-only/«в ответе» не создаёт файл.
При сохранении нового плана — [единый шаблон](references/plan-template.md), каталог `.plans/`.
После записи плана сам запусти проверку по [жизненному циклу](references/lifecycle.md).
При делегировании используй результат автора для той же версии файла.
Существующие планы сохраняют формат и путь; при необходимости обнови на месте.
Не изобретай обязательные фазы, проценты и документы без пользы для исполнения.
Верни план либо путь к нему, следующий шаг и блокирующие вопросы. Планирование не запускает реализацию.
Если план сохранён/изменён, основная сессия оформляет внутреннюю запись по
`.codex/rules/history.md`: описывай планирование, не объявляй фичу реализованной.
