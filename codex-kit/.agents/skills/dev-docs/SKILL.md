# Документация

Прочитай `AGENTS.md`, применимые правила и `.codex/project.md`.
Определи аудиторию, изменённое поведение и целевые документы.
Небольшую правку сделай сам. Большой согласованный набор поручай одному
`kit_documenter` по [runtime](../dev-cycle/references/runtime.md).
Передай пути и факты, которые нужно проверить; полную историю разработки не копируй.
Не меняй прикладной код и чужие документы вне задания.
Если пользователь явно просит документацию с нуля, создай её в принятой структуре.
Общий журнал генерируется сборщиком, не дописывается вручную.
Основная сессия фиксирует выполненную правку отдельной записью по `.codex/rules/history.md`.
Верни изменённые пути и непроверенные сведения, если они остались.

## Пользовательские инструкции

Строй инструкцию вокруг конкретной задачи пользователя. Укажи, где начать, и какие
права или настройки нужны, если они влияют на выполнение. Дай шаги в рабочем порядке,
используй точные названия элементов интерфейса и опиши ожидаемый результат там,
где он помогает проверить успех. Для типовых ошибок укажи способ восстановиться.
При делегировании пользовательской инструкции передай эти требования `kit_documenter`.
