# История разработки этого комплекта

В `entries/` хранятся реальные записи об изменениях проекта `agentic_ai`.
Они не входят в переносимый шаблон: в другие проекты копируется содержимое `codex-kit/`.

Из этого репозитория инструмент вызывается так:

```powershell
python codex-kit/.codex/scripts/changes.py check
```

[Формат и команды](../codex-kit/.changes/README.md).
